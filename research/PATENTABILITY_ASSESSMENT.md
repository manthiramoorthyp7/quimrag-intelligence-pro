# Patentability Assessment — Evidence-Adaptive Retrieval & Verification (EAR)

**This is a preliminary technical prior-art scan, not a legal opinion.** It does not establish novelty, non-obviousness, or freedom to operate, and it is not a substitute for a professional patentability search or a qualified patent attorney's review. Searches were run via web search (October 2026) against arXiv, Google Patents, and general web sources; this is not an exhaustive, access-controlled, or multi-database (USPTO/EPO/WIPO full-text) search.

## What was searched

1. `patent "adaptive retrieval" OCR confidence retrieval-augmented generation evidence sufficiency abstain`
2. `patent "retrieval-augmented generation" abstention selective prediction confidence calibration`
3. `site:patents.google.com retrieval augmented generation OCR confidence adaptive`
4. `"dense" "sparse" retrieval disagreement signal confidence trigger reranking patent`
5. `numeric contradiction detection conflicting evidence passages RAG verification`

## What EAR actually is (for comparison)

A decision layer over an existing hybrid (dense + BM25 RRF) retriever that computes four signals from retrieval that has already happened — (a) Jaccard agreement between dense-only and BM25-only top-K rankings, (b) mean OCR confidence of the retrieved evidence (propagated from Tesseract word-level confidence, not estimated), (c) a lexical-overlap-gated numeric-disjointness heuristic for cross-passage contradiction, (d) a query-complexity heuristic — combines them via a logistic regression calibrated on labeled data, and maps the resulting probability to one of four actions (answer / expand retrieval / inspect structure / abstain), with decision thresholds also chosen from calibration data (precision-constrained for "answer", a percentile for "abstain"). Evaluated as a selective-prediction (risk-coverage) problem, not as a retrieval-ranking method.

## Assessment

- **The general pattern "compute a confidence/sufficiency signal and decide whether to answer or abstain in RAG" is well-established prior art as of 2026** (SURE-RAG, the evidence-sufficiency benchmark, AB-RAG, ConRAG, and others above). Any patent claim resting on that pattern alone would very likely fail on novelty/obviousness grounds.
- **Using dense/sparse retrieval agreement as a signal is independently prior art** (the "Retrieval Disagreement as a Signal" paper, AgreRank) and **using OCR confidence to drive a downstream decision is prior art in the adjacent OCR-extraction patent space** (EP3588376A1 / US20200005089A1).
- **What is comparatively less precedented in what was found here:** the specific combination of (dense-sparse rank-overlap) + (propagated OCR word-confidence, not a learned OCR quality estimator) + (a zero-inference-call numeric-disjointness contradiction heuristic) + (query-complexity heuristic), fused via a logistic regression explicitly calibrated against a four-way action space (answer / expand-retrieval / inspect-structure / abstain) rather than a binary answer/abstain gate. No prior art found here combines exactly this signal set with this action space.
- That said, a four-signal logistic fusion into a threshold-based decision is a **fairly standard ML pattern** (feature engineering + logistic regression + calibrated thresholds). A patent examiner could reasonably argue the combination is an obvious application of known techniques (dense-sparse agreement, OCR confidence, contradiction detection) to a known problem (RAG abstention), especially given how crowded this specific sub-area became in papers dated just months before this project (2026).

## Conclusion

**Not a clear patentability candidate as currently scoped.** The core techniques (adaptive abstention in RAG, dense-sparse agreement as a signal, OCR-confidence-driven decisions) are each independently established in recent literature and adjacent patents. If the user wants to pursue IP protection, the narrowest, most defensible angle found here is the specific four-signal combination plus the four-way (not binary) action space plus the zero-inference contradiction heuristic — and even that should go through a professional, full-database prior-art search (including a full read of US20250390520A1) before any filing decision, since this scan used only public web/arXiv/Google-Patents search and is not exhaustive. Do not publicly disclose implementation specifics beyond what is already in this repository before making a filing decision, if filing is being considered.

## Update after closing the four research gaps (`research/IMPLEMENTATION_ROADMAP.md`)

This section reflects the additional evidence gathered in `research/OCR_ROBUSTNESS_STUDY.md`, `research/GENERATION_EVALUATION_REPORT.md`, `research/RVQ_RECALL_ANALYSIS.md`, and `research/NDSU_REPRODUCTION_REPORT.md` — it does not change the conclusion above, only its evidentiary basis.

- **EAR's selective-prediction claim is now validated on two independent datasets** (the original 420-question OHR-Bench subset and a disjoint 70-question substitute-data sample), both showing consistent, statistically-supported improvement. This strengthens the *evidence* behind EAR as a working mechanism; it does not change the prior-art picture — the general pattern (confidence-gated RAG abstention) remains well-populated in 2026 literature, as found above.
- **The `ocr_confidence` signal is now shown to be built on a well-calibrated underlying measurement** (Pearson r=−0.98 against real CER under controlled degradation), but EAR's own weighting of it remains near-zero in every calibration run performed so far, for an identified, documented reason (calibration-set design, not signal invalidity). A patent claim resting on "OCR-confidence-gated retrieval decisions" would need to demonstrate the mechanism actually using that signal in practice, which this project has not yet achieved end-to-end — a real gap in any novelty argument resting on that specific signal, stated plainly.
- **The RVQ quantize-then-exact-rerank fix** (`research/RVQ_RECALL_ANALYSIS.md`) is a direct, undisguised application of the well-known IVF-PQ-plus-reranking pattern from the product-quantization literature (Jégou, Douze & Schmid 2011 and its many descendants) — explicitly not a novel technique, and not presented as one here.
- **The NDSU substitute-data reproduction** is a validation/evaluation exercise, not a technical contribution, and has no patentability relevance.

No part of this update changes the headline conclusion: the project's strongest, evidence-backed claim is a working, now twice-validated engineering system, not a patentable novel technique distinct from the active 2026 prior art already identified above.
